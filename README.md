# INFINITAS Records

beatmania IIDX INFINITASの公式CSVを使ってプレーデータを記録・比較できる非公式ファンツールです。
CSVを取り込むと収録楽曲の情報とあわせてスコアやクリアランプの推移を確認できます。

## 主な機能

- **ダッシュボード** — 過去の記録と比較してスコアやクリアランプの更新、レベル別・収録バージョン別のクリア進捗を確認できます。
- **楽曲検索** — 曲名・アーティスト・収録バージョン・譜面レベルなどで絞り込めます。CSVを登録すると譜面ごとのスコアやプレー履歴も確認できます。
- **データ管理** — 公式CSVをSP/DPそれぞれ最大100件までブラウザに保存できます。保存したCSVは個別にダウンロードでき、プレースタイルごとにZIPで一括エクスポートすることもできます。
